# BlockMash – Asset Audit

Goal: **no Mojang/Microsoft asset (art, sound, font, text) ships in the repo or in `dist/`.**
Verified automatically by `pnpm verify-assets` (`tools/free-assets/verify_no_mojang.py`), which runs at the end of
`pnpm build`. It compares byte hashes and decoded pixel hashes of every file in `dist/` against the vanilla
`minecraft-assets` package (reference-only devDependency `mc-assets-reference`) plus 109 hashes of files removed from
upstream (`tools/free-assets/upstream-removed-hashes.json`), and probes for vanilla `en_us` strings.
Last result: `OK: no Mojang asset found` over the full dist.

Git history was rewritten so the upstream Mojang-derived files never appear in any commit of this repo.

## Open items / honest caveats
- **Structural data**: block model/blockstate JSON (cube geometry, UV tables) and `entities.json` / `.obj` entity geometry
  are still derived from the vanilla structure (via minecraft-assets / prismarine-viewer). They contain no artwork, but they
  are Mojang-derived data. 258 models and 58 blockstates come from PureBDcraft instead. Replacing the rest needs a
  generator of our own geometry.
- **Trademarks**: "Minecraft" is a trademark of Mojang/Microsoft. BlockMash is not affiliated with them. Only protocol/version
  identifiers are used in code.
- **PureBDcraft terms**: non-commercial only, with visible credit (main menu footer + credits page). Public hosting of the
  generated atlas should be confirmed with BDcraft's current terms before publishing.
